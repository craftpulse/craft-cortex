     `cortex:bulk_entries:idem:{userId}:{key}` (and similar for scaffold_entries).

     10K without `force` → ToolException naming cap + escape mechanism.

     decision 9). Optional `'fail'` opts into strict mode: first denied row
     aborts with -32002 listing every denied row that was found.

  7. **`progressInterval` arg, default 100 rows.** Yield one progress frame
     every N rows processed (success + skipped + failure all count). Amends
     locked decision 7's "after every row" → "after every progressInterval
     rows."

  8. **Fixture extension: ~150 throwaway "minor characters" hero entries**
     added to a marvel-seed companion migration before writing 8.7 tests.
     Per-test factories acceptable but seed extension preferred for
     centralised, re-runnable test data.

     src/mcp/transport/SseEmitter.php source before builder dispatch. If

  4. **Trait stack for Pro mutation tools** (since 8.4 extraction):
     `ProToolTrait + PermissionedToolTrait + IdempotencyTrait` + `extends AbstractTool`.
     - PermissionedToolTrait — provides `_assertPermission(array $arguments)`
       that walks `_requiredPermissions($arguments)` and throws -32002 on miss.
       Tools override `_buildPermissionDeniedMessage()` for rich-format errors.
       Tag opts out (returns [] from _requiredPermissions, uses _assertAdmin()).
     - IdempotencyTrait — provides `_idempotencyCacheHit / _cacheIdempotencyEnvelope`.
       Each tool declares `IDEMPOTENCY_CACHE_PREFIX` constant.
     - AbstractTool — provides `_resolveSiteId / _resolveOptionalSiteId /
       _applyFields / _validationEnvelope`.
     - **For 8.7 streaming tools, also implement StreamableToolInterface**.

  5. `_requiredPermissions(array $arguments): array` convention.
     Reference shape at src/tools/content/Entry.php:378.

         protected function _requiredPermissions(array $arguments): array
         {
             $mode = $this->_mode($arguments);
             $scopeUid = $this->_resolveScopeUid($arguments);
             if ($scopeUid === null) {
                 return match ($mode) {
                     'delete' => ['deletePerm:*'],
                     default => ['savePerm:*'],
                 };
             }
             return match ($mode) {
                 'create', 'update' => ["savePerm:{$scopeUid}"],
                 'delete' => ["deletePerm:{$scopeUid}"],
                 default => [],
             };
         }

     filterFor() consults with empty args (walks user permissions); execute()
     re-checks with resolved args. -32002 on miss. Defense in depth.

  6. Validation envelope for content validation failures (NOT exceptions):
         return [
             'success' => false,
             'errors' => $element->getErrors(),
             'mode' => $mode,
             'id' => $element->id,
         ];
     ToolException is reserved for permission denial, missing args, mode
