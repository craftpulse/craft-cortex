LOCKED ARCHITECTURAL DECISIONS (DO NOT VIOLATE)
───────────────────────────────────────────────────────────────────────────────

1. **`getInputSchema()` is edition-aware** for any Free tool that gains
   Pro modes. Returns Free + Pro enum on Pro installs, Free-only enum on
   Free installs. `inputSchemaFor($user)` layers permission filtering on
   top for HTTP callers on Pro. Reference: `docs/plans/gate-8.md` decision 6
   (updated 2026-05-19 in commit `ad40c97`). Reference implementations:
   `src/tools/workflow/DraftsAndRevisions.php`,
   `src/tools/system/Diagnostics.php`, `src/tools/workflow/Audit.php`,
   `src/tools/workflow/ImportExport.php`.

2. **NO numeric `-32002` code on error envelopes.** Wire shape is
   `{content: [{type: 'text', text: '...'}], isError: true}` per
   `src/mcp/Server.php:1327-1335`. The mode-denial invariant is
   **message-text prefix uniformity**, locked by
   `tests/Architecture/ModeErrorShapeTest.php`. Permission-denial messages
   start with the locked prefix template (e.g. ``"permission denied —
   mode `apply` requires `saveEntries:{uid}`."``). Edition-denial messages
   start with ``"<tool>: mode `<mode>` is unavailable on this edition."``.
   **Never add a `code` field to a tool-error response envelope.**

3. **`execute()` drains `stream()` for identical terminal envelope.**
   No shape divergence between JSON and SSE transports. Locked for
   bulk_entries, scaffold_entries, resave, content_audit, import_export.
   Pattern: `tests/Tools/Content/BulkEntriesTest.php` is canonical.

4. **`FiberProgressBridge` cancellation contract**: throwing
   `craft\errors\OperationAbortedException` (or `yii\db\Exception` — verify
   against `vendor/craftcms/cms/src/services/Elements.php:1677` for the
   exact type Craft's catch-block handles) INTO the Fiber engages Craft's
   clean-exit path. Throwing any other Throwable bubbles out of
   `resaveElements()` and breaks the fail-silently contract. Documented in
   `src/tools/support/FiberProgressBridge.php` class docblock as a hard
   invariant.

5. **PC-writing tests are SEQUENTIAL ONLY**. Any test calling
   `Fields::saveField()`, `Users::saveLayout()`, or any service method that
   triggers PC sync must NOT run under parallel execution. Documented in
   `.claude/rules/testing.md` and as a `**SEQUENTIAL ONLY**` callout in
   each PC-writing test's class docblock (today only
   `tests/Services/UserCustomFieldAllowlistTest.php`).

6. **Free editions never advertise Pro modes.** Even on stdio (trusted
   local user). The edition gate runs in `getInputSchema()` itself so
   `tools/list` returns the Free-only enum on a Free install regardless of
   transport. Stdio's "trusted local" semantic in PLANNING.md §4.4 / Gate 7
   decision 3 applies to *permission* gating; the *edition* gate is a
   separate, install-wide concern.

7. **Pro tools through the dispatcher in tests**: use
   `cortex_with_pro_registry()` at `tests/Pest.php`. The existing
   `cortex_with_edition('pro', ...)` flips `$plugin->edition` but does NOT
   rebuild the registry — Pro tools stay invisible to `dispatch()` until
   the rebuild happens. Reference: `tests/Mcp/StreamingTest.php:45-58`
   (the pre-existing rebuild pattern) and the new
   `tests/Integration/PermissionBoundaryTest.php` dispatcher-driven case.
